## SECTION 6 Interactive Features — Cart, Quantity & Checkout Logic

#### Quantity Stepper (All Pages)

- Default state: orange '+ Add' button on each product card
- On first click: button converts to − [qty] + stepper (no page reload — pure JavaScript)
- Subsequent clicks: qty increments/decrements; if qty reaches 0, reverts to '+ Add' button
- Stepper styling: left button (−), centre displays current quantity, right button (+) — all same height
- Developer note: use data attributes on card for product ID, price, name — JS reads these to update cart state

#### Live Cart Badge (Nav)

- Cart icon in top-right navigation shows live count of items
- Badge updates instantly on every Add / Remove / Qty change — no page reload
- Shows 0 when empty (or hide badge), shows total item count when items present

#### Bottom Cart Bar

- Hidden by default — slides in (or appears) when first item is added to cart
- Shows: '[N] items in cart' | 'Total: $XX.XX' | 'View Cart & Checkout' button
- Total updates live as quantities change on the page
- Present on: all category pages, product pages — persistent until cart is cleared

#### Cart Drawer (Product Detail Page)

- Opens as a panel at the bottom of the page (not a popup overlay — avoid position:fixed)
- Lists all cart items: icon, name, meta info, per-item qty stepper, line price, remove (X) button
- Summary block: subtotal, delivery fee, coupon discount, tax (7%), order total
- Proceed to Checkout button — links to /checkout
- Continue Shopping button — collapses drawer, keeps user on product page

#### Checkout Coupon Logic

- Coupon input field + Apply button — enter code and click
- On valid code (e.g. HALAL10): show green success message, apply 10% discount, recalculate all totals
- Discount line appears in summary: '− $X.XX' in green
- Order total, tax, and Place Order button total all update instantly
- Invalid code: show red error message 'Code not found — please check and try again'

#### Checkout Cart Editing

- Right panel on checkout page shows full cart with per-item qty steppers
- Changing qty on checkout page recalculates: subtotal, tax (7%), delivery fee, order total
- Removing all of an item removes the row from the cart summary
- Place Order button label dynamically shows running total: 'Place Order — $51.82'

#### Order Confirmation

- After Place Order: confirmation screen slides in below checkout (or replaces checkout view)
- Unique order ref generated: #CHM-2026-[random 4-digit number]


- 3-step visual: Order Received → Ready in ~2 hrs → Collect / Delivery
- SMS + email triggered automatically via WooCommerce hooks
- Download Receipt button generates PDF order summary

## SECTION 8 E-Commerce & Clover POS Requirements

#### Core E-Commerce Features

- Product listings: photos (min 800x800px WebP), description, price, weight, unit size, SKU
- Search with filters: category, brand, price range, dietary (halal-only)
- Quantity stepper on all product cards and product detail pages
- Guest checkout + optional account creation
- Order types: In-Store Pickup (time slots), Curbside, Local Delivery
- Payment: Credit/Debit card via Stripe, Apple Pay, Google Pay, Pay In-Store
- Coupon/promo codes — percentage or fixed amount, expiry dates
- SSL (HTTPS) — mandatory before accepting any payments

#### Clover POS Integration

- Real-time inventory sync via SKULabs or Connectify middleware
- Product catalogue sync — items in Clover appear on website automatically
- Online orders push to Clover as new transactions for staff to see
- Fallback option: weekly CSV export/import if middleware budget is deferred to Phase 2

#### Customer Notifications

- Order confirmation email (branded) — sent automatically after purchase
- Order ready SMS via Twilio or WooCommerce SMS plugin
- Weekly specials newsletter via MailChimp or Klaviyo
- Abandoned cart recovery: 1hr, 24hr, 48hr email sequence

#### Admin Backend

- Dashboard: all orders (online + in-store), inventory, price management
- Bulk product CSV upload for initial 500+ product catalogue
- Discount manager: weekly specials, Ramadan deals, first-order codes
- Sales reports: revenue by category, top products, peak order times


## SECTION 9 Google SEO Strategy & Schema Markup

#### Local SEO Strategy

- Google Business Profile: categories = Grocery Store + Halal + South Asian Grocery, full photos, hours, weekly posts
- NAP consistency: Name, Address, Phone identical on website, GBP, Yelp, Bing, Facebook, Zabihah.com
- Zabihah.com listing: most important halal-specific directory — Muslim community checks this first
- Embed Google Maps on Contact page and in every page footer

#### On-Page SEO

- Unique meta title (50–60 chars) and meta description (150–160 chars) on every single page
- One H1 per page — contains primary keyword — never duplicated across site
- URL slugs: short, keyword-rich — no dates, no random characters
- Internal linking: every page links to 3–5 related pages
- Image alt text: descriptive, keyword-containing alt on every image — compress all to WebP
- Page speed: target under 3 seconds mobile via WP Rocket + Smush

#### Schema Markup Required

- LocalBusiness / GroceryStore — homepage with coordinates, hours, service area
- Product + Offer — every product page for Google Shopping listings
- BreadcrumbList — all category and product pages
- FAQPage — FAQ page each Q&A; for Google rich result snippets
- Review / AggregateRating — homepage and product pages for star ratings in search
- SiteLinksSearchBox — homepage for Google Knowledge Panel search feature

#### Technical Checklist

- XML Sitemap: auto-generate via Yoast SEO, submit to Google Search Console on launch day
- HTTPS / SSL: free Let's Encrypt, must be active before launch
- Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms
- Mobile-Friendly Test: must pass before launch
- Canonical tags on all pages to prevent duplicate content
- Custom 404 page with navigation links

#### Blog & Content Strategy

- 2–4 posts/month targeting long-tail searches: halal biryani recipe, Ramadan grocery guide, etc.
- Minimum 800 words, 1–2 target keywords, internal links to product pages
- Recipe posts use Recipe schema for Google rich results (cook time, ingredients, steps)

## APPENDIX A Checkout Flow — Step-by-Step Specification

#### Step 1 — Cart Review

- All items listed: icon, name, quantity stepper (−/+), line price, remove (X) button
- Subtotal updates live on every qty change
- Coupon input at bottom: enter code → Apply button
- Proceed to Checkout button shows live cart total

#### Step 2 — Delivery or Pickup

- Two cards: In-Store Pickup (FREE) and Local Delivery ($3.99) — click to select
- Pickup: time slot grid — available clickable, booked shown struck through
- Delivery: zip code checker — only enable if within WooCommerce delivery zone
- Estimated ready time: 'Your order will be ready in approximately 2 hours'

#### Step 3 — Contact Details

- Fields: first name, last name, phone, email, delivery address (if delivery selected)
- Phone: used for SMS confirmation; email: used for order receipt + newsletter opt-in

#### Step 4 — Payment Method

- Options: Credit/Debit Card (Stripe), Apple Pay, Google Pay, Pay In-Store (pickup only)
- Card form: number (auto-spaced), expiry MM/YY, CVV, name on card
- Stripe handles all processing — PCI DSS compliant, no card data stored on server

#### Step 5 — Review & Place Order

- Full order summary right panel: items, delivery fee, discount, tax (7%), total
- Place Order button locked until all required fields complete
- Button label shows live total: 'Place Order — $51.82'
- SSL lock icon + '256-bit SSL Secured' reassurance note below button

#### Step 6 — Order Confirmation

- Unique order ref: #CHM-2026-[4-digit random]
- Message: 'JazakAllah Khair! Your order is confirmed.'
- 3-step visual: Order Received → Ready in ~2 hrs → Collect at Store
- Auto-SMS to customer phone + auto-email with itemised receipt
- Download Receipt (PDF) + Continue Shopping CTA
